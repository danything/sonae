# 画面

sonae の画面は 1 つです (`src/routes/+page.svelte`)。地図が主で、全部の種類を新しい順に並べた 1 本の一覧と、選んだものの詳しい内容を同じ画面に置きます。
見た目の決まりは [design.md の 6 章](design.md#6-見た目と動きの決まり) (denpa の決まりに従う) です。

## 一覧

- 地震・津波・緊急地震速報・火山・気象・海外・お知らせを、種類をまたいで時刻の新しい順に 1 本に並べ、日付の見出しで区切ります。府県予報区の気象警報・注意報の行は、その府県予報区のいちばん新しい報の時刻に並びます (出ている間は残ります)
- 種類のチップ (件数つき) は絞り込みです。先頭の「すべて」(全部の件数) と種類ごとのチップで、全部か 1 つの種類を出します。
  全部出ているときに種類のチップを押すとその種類だけ、出している種類のチップをもう一度押すか「すべて」を押すと全部、別の種類のチップを押すとその種類だけに切り替わります。
  出しているもの (「すべて」か 1 つの種類) は主の色の太字と字の幅いっぱいの下線で、押されているボタン (`aria-pressed`) です。どれもボタンなので Tab で移り、Enter かスペースで押せます。
  選んだものは端末に覚えます (localStorage の `sonae.list.only`。全部のときは覚えない)。前の形の `sonae.list.hidden` (隠した種類の配列) は読まず、開いたときに消します。既定は全部出します。詳しい内容を見ているときに押すと、一覧へ戻ります
- 一覧の先頭には、次のものを通知の形で出します。いま出ている緊急地震速報 (取消を除く)・大津波警報と津波警報・気象の特別警報 (レベル 5) は、チップにかかわらずいつも出し、この順に並べます。
  その後に、いま出ている津波注意報・津波予報、1 日以内の噴火速報といま出ている噴火警報 (居住地域)、この 1 週間の南海トラフ地震の情報と地震・津波に関するお知らせが、その種類を出しているときだけ続きます。押すとそれぞれの詳しい内容が開きます
- 住んでいる地域 (「通知」で選んだ市町村) に、今日から先で警報級の可能性 (早期注意情報) が「高」「中」の日があれば、一覧の先頭 (通知の形のものの下、日付の見出しの上) に控えた字の 1 行で「住んでいる地域の警報級の可能性」と「明日 大雨 中・土砂災害 中、11/24 (火) 雨 高」のように出します (気象のチップを出しているときだけ)。面も色も付けません。
  押すと、その府県予報区の詳しい内容 (`?w=office-<コード>`) が開き、最後に一次細分区域ごとの「警報級の可能性」の節が出ます。警報・注意報が出ていない府県予報区でも、警報級の可能性だけを出します。知らせには使いません ([design.md の 2.8](design.md#28-気象の警報注意報と気象の報) の「早期注意情報」)
- 行は件の面に乗った 2 段です。1 段目に時刻とタイトル (震源・区分)、2 段目に控えた字の補足 (M・深さ・警報の地域) です。左には震度・津波の区分・火山や気象の段のラベルが付き、ラベルの無い種類も同じ幅を空けて、時刻とタイトルの始まりをそろえます。
  緊急地震速報と海外の地震は、2 段目の先頭に「緊急地震速報 (警報)」「緊急地震速報 (予報)」「海外の地震」と種類を書きます
- 長周期地震動階級 1 以上を観測した地震は、行の 2 段目に「長周期地震動階級3」と出ます。地震の詳しい内容には「長周期地震動」の節があります ([design.md の 2.7](design.md#27-長周期地震動と推計震度分布))
- 気象の行は、府県予報区の警報・注意報 (いちばん高い段のラベルと、出ている種類の名前) と、気象の報 (記録的短時間大雨情報・気象防災速報・竜巻注意情報・指定河川洪水予報・熱中症警戒アラート・台風情報) と、解説の情報 (気象解説情報・気象解説情報 (潮位)・天候情報・早期天候情報) です。台風は台風ごとに、気象解説情報は一連の情報 (同じ台風・同じ大雨の第 1 号からの続き) ごとに、いちばん新しい報だけを出します。解説の情報は種類のチップを分けず、2 段目の先頭に種類を書きます。府県の解説 (府県気象解説情報と府県の潮位の解説) は全国で 1 日に数十通出るので、「すべて」では住んでいる地域 (「通知」で選んだ市町村) の府県予報区・一次細分区域のものだけを出し、住んでいる地域を選んでいなければ出しません。気象のチップでは全部を出します。指定河川洪水予報の行には、基準観測所のいまの水位 (「上川沿 6.19 m (14:50)」) を添えます。詳しい内容には、本文を「気象概況」「防災事項」「雨の予想」などの節に分けて、電文の文のまま出します ([design.md の 2.8](design.md#28-気象の警報注意報と気象の報) の「解説の情報」)。
  府県予報区の行を押すと、種類ごとの対象の市町村等と、現象ごとの見出しの文が出ます。指定河川洪水予報を押すと、観測所ごとの実況と予想の水位と、氾濫注意水位などの基準の水位が出ます ([design.md の 2.8](design.md#28-気象の警報注意報と気象の報))
- 火山の行は、噴火警報・予報 (段のラベルと引上げ・継続、対象の市町村)・噴火速報と、解説情報・観測報・降灰予報・推定噴煙流向報 (2 段目の先頭に「降灰予報 (速報)」のように種別を書き、見出しか噴煙を続ける) です。段のラベルは噴火警報・予報と解説情報と噴火速報だけに付けます。
  観測報・降灰予報 (定時)・推定噴煙流向報は数が多いので、この 2 日の報から、火山と種別ごとにいちばん新しい報だけを出します。詳しい内容には、降灰予報なら「降灰の範囲」(「やや多量の降灰」などの種類ごとの市町村)、観測報などなら「噴煙と観測」が出ます。降灰の範囲は地図に描きません ([design.md の 2.2](design.md#22-正規化したイベントのモデル) の「火山」)
- 海外の地震 (USGS など) も同じ一覧に並びます。地図の初めの範囲は日本のままで、海外の地震を選ぶと地図が引いてその震央へ寄ります
- 行を押すと、一覧の列が詳しい内容に替わり、地図もその地震に寄ります。左上の「一覧」で戻ります (種類のチップは残ります)。戻ると、地図も開く前の位置へ戻ります。開いている間に地図を動かしたときは、動かした所のままです ([map.md](map.md) の「詳しい内容を閉じたら戻す」)
- 地震を選ぶと、地図に地域ごとの震度の塗りと数字に加えて、震度観測点ごとの震度を震度の色の小さな丸で出します (大きい震度が上。寄せると丸が大きくなり、地域の塗りは薄くなります)。位置の分からない観測点は出さず、詳しい内容の「観測点の震度」の下に「地図に出していない観測点 (n 点。位置の表にありません)」と名前を出します ([map.md](map.md) の「観測点ごとの震度」)。
  丸を押す (スマホの形はタップ。丸より少し広く押せます) と、吹き出しに観測点の名前 (「＊」は外します)、震度のラベル、都道府県と市町村 (「静岡県・西伊豆町」)、設置者 (「気象庁の観測点」「地方公共団体の観測点」「防災科学技術研究所の観測点」) が出ます。地図にフォーカスがあるときは、Esc で吹き出しを閉じます
- 地震を選んでいる間は、地図の気象警報・注意報の塗りを隠します (震度の色と重なって読み違えるため)。いま出ている特別警報は縁取りで残し、緊急地震速報と津波の線はそのまま出します。右下の操作の上に「地震を選んでいる間は、気象警報・注意報の塗りを隠しています。一覧へ戻ると元に戻ります。」と出ます。一覧へ戻るか、府県予報区の警報・注意報を選ぶと、また塗ります ([map.md](map.md) の「地震を選んでいる間」)
- 何も無いときは「まだ情報を受けていません」、絞り込みの欄かチップで当てはまるものが無いときは「当てはまるものはありません」と出します
- 一覧のいちばん下に注意文と短い出典があります (どちらの形も)。出典の全文は「出典と注意」の窓で、短い出典のリンクからも開きます
- 地図の右下に短い出典 (「出典: 国土地理院・気象庁 ほか」。ハザードマップを重ねているときはハザードマップポータルサイト (活断層は都市圏活断層図。どちらも、選んだ図がいまのズームで重なっているときだけ)、沖ノ鳥島のあたりの写真を映しているときは GRUS 画像も) がいつも出ます。押すと「出典と注意」の窓が開きます。スマホの形では地図の右上の角に出ます (下は浮いた下のタブ・dock・操作が重なるため)
- どの情報源を受けているかは、「出典と注意」の窓の「受信の状態」にいつも出ます (どちらの形も。注意文と、緊急地震速報の予想震度を出さないことの説明の下)。画面への配信と、情報源ごとの状態 (「受信中・11/15 23:44」のように最後に受けた時刻つき) を並べ、開いている間も替わります。
  「Wolfx Project」の行は、緊急地震速報と地震情報の一覧 (P2P地震情報の予備) を受ける 1 本の接続の状態です。
  設定で切ってある情報源は「オフ (授権碼がありません)」のように訳を添えて並べます (授権碼の無い中央氣象署と、API のキーの無い海しると、`SONAE_ROAD_DISCOVER=off` で自動の発見を切り、URL も登録していない通行止めと、`SONAE_TREM=off` で切った TREM、`SONAE_SEISJS=off` で切った SeisJS)。オフは問題ではないので、控えた字のままで注意の印も出しません。つながっていないものだけ注意の色の字にします。
  「国土交通省 (災害時の通行止め)」の行には、いま国土交通省の一覧にある災害の名前と数と、最後に一覧を確かめた時刻を出します (「受信中・令和8年熊本地震 (1 件)・11/21 10:00 に一覧を確かめた」)。災害が無いときは「災害の通行止めはありません (11/21 10:00 に確かめた)」、一覧のページが読めないときは「一覧が読めません」を注意の色の字で出し、見分けられるようにします ([design.md の 2.12](design.md#212-災害時の通行止め))。
  持ち主の声「同期中のデータがどれかわからん」「できるだけ要素とか画面は増やさない方向で」から、ボタン・タブ・画面は足さず、いつも開ける窓に入れました

## 広い形 (1000px から)

- 上に全幅のヘッダー。左にロゴと名前、真ん中に地名で絞り込み・住所で探す欄 (`/` か Ctrl+K で移る)、右に字だけのナビ (「出典と注意」・「通知」・利用者の名前のメニュー。ログインしていないときは「通知」を出さず、メニューの名前は「メニュー」)。
  欄に打つと一覧を地名で絞り、欄の下に「場所の候補」(市町村と、国土地理院の住所検索の住所・地名) を出します。↑↓で選んで Enter (押してもよい) で地図がそこへ寄り、橙の丸の印が付きます。Enter を押すか打つのが少し止まると住所も探します。Esc で候補を閉じます ([map.md](map.md) の「場所の検索」)
  「通知」の窓は、上から通知の条件、「開いているとき」(OS の通知と音と読み上げ)、「Web Push (タブを閉じていても届く)」、「Webhook (Discord・Slack など)」、「ブラウザの通知の状態 (うまくいかないとき)」です ([push.md](push.md))。
  条件は、先頭の住んでいる地域 (都道府県と市町村の選択と「現在地から選ぶ」。下に、地震の細分区域・津波の予報区のどれで照らすかを出します。選んでいないときは、そのときの扱いを出します) と、緊急地震速報・地震・津波・火山・気象の 5 つの選択です。
  5 つはどれも同じ選択肢「全国のものを知らせる」/「住んでいる地域と現在地のものだけ」/「知らせない」で、選択のすぐ下に、選んでいるもので何を知らせるかを 1 文で出します (「最大震度4以上の地震と、住んでいる地域か現在地で震度3以上の地震を知らせます。」)。何の段から知らせるか (注意報も・火口周辺警報も) は選べず、[design.md の 2.4](design.md#24-web-push) の表の既定値で決めます。
  地震だけは、範囲が「知らせない」でないとき、範囲のすぐ下に「地震を知らせる震度」(震度1以上〜震度7以上) の選択が出ます。選んでいなければ範囲の既定 (全国は最大震度4、住んでいる地域と現在地は震度3) を出します。範囲を替えると、既定のままの震度は替えた先の既定に変わり、選んだ震度は残ります。
  「知らせない」の 1 文は、津波なら「特別警報にあたる大津波警報だけを知らせます。」、火山なら「特別警報にあたる噴火警報 (レベル 4・5) だけを知らせます。」です。気象は「知らせない」なら「特別警報だけを、どこに出ても知らせます。」で、ほかの範囲の 1 文は「注意報だけの通知は 1 日 1 回までです。」で終わります。
  特別警報にあたるもの (気象の特別警報・大津波警報・噴火警報 (レベル 4・5)) と、南海トラフ地震臨時情報・南海トラフ地震関連解説情報 (定例外)・後発地震注意情報は、「知らせない」を選んでもいつも知らせます。スイッチは置かず、5 つの選択の下に 1 文で書きます。
  「開いているとき」は、「OS の通知を出す」のスイッチ、「音と読み上げ」の選択 (「オフ」/「通知音だけ」/「読み上げも」。読み上げに対応しないブラウザでは「読み上げも」を選べません)、「読み上げも」のときの「声」の選択、「試しに鳴らす」と、地図の現在地をどう使うか・いまいる市町村の 1 文です。
  声はこの家の全部の端末で同じで、選んだらすぐサーバーに保存します (まだ選んでいなければ剣崎雌雄)。
  「試しに鳴らす」は、いまの選択どおりに鳴らします。通知音だけなら音を、読み上げもなら音の後に選んである声で試しの文を読みます。オフのときは出さず、声を保存している間は押せません。
  Web Push の節は「このブラウザで受ける」(登録した後は「試しに送る」と「解除」) と、ほかのブラウザの購読の一覧 (「解除」つき) です。Webhook の節は、URL の欄と「追加」、足した送り先の一覧 (送り先のホスト・直近の結果・「試しに送る」・「解除」) だけです。URL は秘密なので、足した後は欄から消し、一覧にもホストだけを出します。
  「ブラウザの通知の状態」は、開くとブラウザが返す値 (安全な接続か・`Notification.permission`・`pushManager.permissionState`・アプリとして開いているか・UA など) をそのまま並べます。
  開いているときの知らせ (通知・音・読み上げ) がオンの間は、裏のタブでも止まらないようにします (Web Lock を持ち続ける)。パソコンの Edge では、それだけでは眠らせることがあるので、「開いているとき」の説明の下に、Edge の設定の「これらのサイトを常にアクティブに保つ」に足すよう一言出します ([design.md の 2.4](design.md#24-web-push) の「裏のタブで止めない」)。
  利用者のメニューには「強震モニタを開く」(防災科研の公式のページを新しいタブで開く)、テーマ (暗い・明るい・端末に合わせる。既定は端末に合わせる) とログアウトがあります
- 受信に問題があるときだけ、ナビの左に注意の印と一言 (「受信に問題があります」「受信が切れています・再接続しています」) が出ます。押すと、画面への配信 (切れている間は「再接続しています」) と情報源ごとの受信をメニューの箱で出します (「出典と注意」の「受信の状態」と同じ並び)。
  画面への配信は切れても自分でつなぎ直し、30 秒続けて切れたら「通知」でオンにしたもの (通知・音・読み上げ) で知らせます (止めるスイッチは置きません。[design.md の 2.3](design.md#23-ブラウザへの配信-sse))
- 通知の音か読み上げがオンなのにブラウザが音を止めている間は、ヘッダーのすぐ下に全幅の帯が出ます (地図と一覧の列はその下から始まり、帯に隠れません)。
  左に注意の色のアイコンと見出し (「音と読み上げが止まっています」)、続けて何が届くか (「押すと、警報を音と読み上げで知らせます」。通知の許可があれば「通知は出ます。音と読み上げも聞くなら押してください」)、右に「音を出す」。帯のどこを押しても鳴らせるようになり、帯は消えます ([design.md の 2.4](design.md#24-web-push))
- 読み上げている間だけ、地図の左下に「読み上げ中断」が浮きます (2026-11-17。持ち主の声「読み上げ中に読み上げ中断ボタンほしい」)。押すか Esc を押すと、読んでいる文もその報の残りの文も読まずに止まります。メニュー・検索の候補・窓が Esc を使うときと、欄に打っている間は、Esc ではそちらが先です。
  音と読み上げの設定は変わらず、次に届いた報はいつもどおり鳴らして読みます
- その下は 2 列です。左の残りの幅がすべて地図で、右が一覧の列 (22rem。1600px から 26rem) です。denpa の観る画面 (映像と右の列) と同じく、主の中身を左、添える列を右に置きます。一覧は列の中で巻きます
- 列の上 (巻かずに残る) に、種類のチップ (入りきらなければ折り返す) と、右端のカレンダーのボタンがあります。
  カレンダーはメニューで開き、行のある日を押すとその日の見出しへ送って閉じます
- 地図の右下に現在地のボタンがあります (スマホの形も)。押すと端末の位置を追い、白い縁の青い点と位置の誤差の円を出し、初めて取れたときだけそこへ寄せます。もう一度押すとやめます。位置はサーバーに送りません。許可されていないときは、右下の操作の並び (ハザードマップの凡例を出していればその上) の上にそう出します。
  **既定はオン**で、初めて開いたときに位置の許可を聞きます。断られたらオフにして聞き直しません。押して選んだオン・オフは端末に覚えます。自動で始めたときは寄せません ([map.md](map.md) の「現在地を自動で始めるとき」)。
  現在地は、開いているときの通知の「住んでいる地域と現在地のものだけ」にも使います
- 地図を右クリックすると (スマホの形は長押し)、押した所に小さいメニューが出ます。見出しに押した所の緯度・経度があり、「ここを住んでいる地域にする」(押した所が入る市町村を、通知の住んでいる地域にする。「通知」の「現在地から選ぶ」と同じ) と「緯度・経度を写す」を選べます。↑↓と Enter で選び、Esc か外を押すと閉じます。地図をドラッグ・2 本指で拡大したときや、長押しの間に指が動いたときは出ません。
  結果は地図の上の真ん中に少しの間出ます (「東京都千代田区を住んでいる地域にしました」。海の上や日本の外では「ここが入る市町村が見つかりませんでした…」と出て変えません)。住んでいる地域が決まっていれば、地図でその市町村を水色の破線で縁取ります ([map.md](map.md) の「地図のメニュー」)
- 地図の右下に「重ねる: なし」の選択があります (スマホの形も)。現在地のボタンと 1 行に並び、隅の出典のすぐ上 (スマホの形は下のタブと dock のすぐ上。出典は右上の角) にあります。マウスでは上に乗せただけで選択肢が上へ開き、外れると少し待って閉じます (乗せて開いてから押すと、外れても開いたまま)。指では押して開き、キーボードでは Enter で開きます。なし・雨雲 (いま)・キキクルの土砂と大雨・ハザードマップ (洪水・内水・高潮・津波・土砂災害)・地震の備え (活断層・揺れの確率 (30 年)・地盤の揺れやすさ) から 1 つを選ぶと、その図を写真の上に重ね (ボタンは「雨雲」「ハザードマップ: 洪水」のように替わります)、その下に公式の凡例 (活断層は国土地理院の説明へのリンク) を出します。洪水を選ぶと、凡例の上のチップで「浸水の深さ」「浸水が続く時間」「家屋倒壊等」(家屋倒壊等氾濫想定区域) を切り替えられます。選んだものは端末に覚えます ([map.md](map.md) の「重ねる図の選択肢」)。
  選んでいる間は、色がぶつからないよう、気象警報・注意報と震度の塗りを隠し、塗った所を押しても吹き出しは出ません。いま出ている特別警報は縁取り、緊急地震速報は赤い縁取りで残します。凡例の下に隠していることと「なし」に戻すと元に戻ることを書きます ([map.md](map.md) の「ハザードマップを重ねている間」)
- 「雨雲」を選ぶと、気象庁の高解像度降水ナウキャストの、いまの降水強度 (mm/h) を重ねます (2026-11-20)。右下に凡例と「11/20 23:25 の観測 (5 分ごとに更新)」のように、いつの観測かを出します。15 分より古い雨雲しか読めていないときは、注意のアイコンと「いまの雨ではありません」に替わります。1 時間先の予測は出しません。
  選んでいる間は、ハザードマップと同じく気象警報・注意報の塗りと通れた道の線を隠します。地震を選んでいる間は雨雲を隠し (色が震度の色と同じため)、右下の操作の上にそう出します。一覧へ戻ると元に戻ります ([map.md](map.md) の「雨雲」)
- 見出し「キキクル (危険度分布)」の「土砂」か「大雨 (浸水・洪水)」を選ぶと、気象庁のキキクルのいまの危険度を重ねます (2026-11-21。ボタンは「キキクル: 土砂」「キキクル: 大雨」)。右下に凡例 (災害切迫・危険・警戒・注意と、警戒レベルの相当) と「11/21 00:50 の危険度 (10 分ごとに更新)」のように、いつの判定かを出します。40 分より古いものしか読めていないときは、注意のアイコンと「いまの危険度ではありません」に替わります。
  雨雲と同じく、選んでいる間は気象警報・注意報の塗りと通れた道の線を隠し、地震を選んでいる間はキキクルを隠します ([map.md](map.md) の「キキクル」)
- 台湾の観測点 (ExpTech の TREM) を小さな灰色の点で置き、地震の間だけ、揺れた観測点をいまの揺れに当たる震度の色で塗ります。非公式の値なので、地図に出すだけで、一覧・音・読み上げ・通知では知らせません。サーバーの環境変数 `SONAE_TREM=off` のときは点も出しません ([design.md の 2.9](design.md#29-台湾の観測点の揺れ-trem-rts))
- Wolfx SeisJS の有志の観測点 (いまは中国と台湾の数か所) も同じ見た目の点で置きます。揺れが計測震度 0.5 以上なら震度の色で塗ります。非公式の値なので、地図に出すだけです。`SONAE_SEISJS=off` のときは点も出しません ([design.md の 2.10](design.md#210-有志の観測点の揺れ-wolfx-seisjs))
- 海上保安庁の海しるの海底地殻変動観測点 (水色のひし形) と海域火山 (黒い縁の白い三角の輪郭) を点で置きます。押す (スマホの形はタップ) と、名前・設置水深か標高・設置機関や位置の出どころと、海上保安庁のページへのリンクが吹き出しで出ます。サーバーに海しるの API のキーが無いときは出しません ([map.md](map.md) の「海しるの点」)
- 国土交通省が災害ごとに出す「通れるマップ」から、いま全面通行止めの道を白い縁の赤い太い線で、ETC2.0 で車が通った道 (通れた道の目安) を細い線 (時速 20 km 以下は橙、21 km 以上は水色) で出します。サーバーが国土交通省 道路局のページから災害を自動で見つけて取ります (見つからない災害は、サーバーの管理者が URL を登録できます)。線を押すと、路線名・区間・規制の内容・更新の時刻が出ます。ハザードマップか雨雲を重ねている間は、通れた道の線だけを隠します ([map.md](map.md) の「災害時の通行止め」)。渋滞や細かい規制は、「出典と注意」の窓のリンク (道路情報提供システム・JARTIC・NEXCO) から見ます
- 写真の上に道路・地名・施設の記号を重ね、大きく寄せると指定緊急避難場所・指定避難所の印 (緑の「避」。福祉避難所は白地に緑の「福」) が出ます。印を押すと、名前・住所・対応する災害と、福祉避難所なら受け入れる人を吹き出しで出します
- 気象警報・注意報で塗った市町村等を押す (スマホの形はタップ) と、吹き出しに市町村等の名前 (「稚内市」)、いま出ている警報・注意報 (重い順。一覧と同じ段のラベル)、発表した府県予報区と時刻 (「宗谷地方・2026/11/15 10:06:00 発表」) と、「宗谷地方の警報・注意報を見る」のリンクが出ます。
  リンクは一覧の府県予報区の行と同じ `?w=office-<コード>` を開きます (スマホの形は一覧のタブへ移ります)。避難場所の印と重なったときは、印の吹き出しだけが出ます。
  吹き出しは地図の上に 1 つだけで、重なったときは上に描いているもの (避難場所の印、観測点の丸、海しるの点、通行止めと通れた道の線、震源の丸、警報・注意報の市町村等の順) を使います。震央の × と震度のラベルは何も持たないので、押すとその下のものが出ます ([map.md](map.md) の「押せる所が重なったとき」)
- 震源の丸 (新しい 50 件の地震) と海外の地震の丸を押す (スマホの形はタップ) と、一覧でその地震を選んだのと同じになります。詳しい内容が出て、地図に震度の塗り・観測点の丸・震央の × が出ます。URL も一覧の行と同じ (`?q=…`・`?f=…`) で、スマホの形は一覧のタブへ移ります。丸は小さいので、押せる範囲は丸より広く取ります (指は 44 px 四方)。マウスでは丸の上で指の形になります。キーボードでは丸を選べないので、一覧で選びます ([map.md](map.md) の「震源の丸を押したとき」)
- 一覧で府県予報区の警報・注意報を選ぶと、地図でその府県予報区の市町村等を白い線で縁取り、出ている市町村等が収まるよう寄せます ([map.md](map.md) の「描き方の決まり」)
- 地図の層はいつも全部出していて、切り替えはありません (ハザードマップ・雨雲・キキクルだけは色がぶつかるので 1 つを選ぶ)。色の意味は「出典と注意」の「地図の見方」にあります ([map.md](map.md))

## スマホの形 (1000px 未満)

- ヘッダーと列は出しません。地図のタブでは地図が画面いっぱいに出て、下に下のタブ (地図・一覧・通知・強震モニタ・その他) が浮きます。ログインしていないときは「通知」を出しません
- **一覧のタブは窓ごと巻きます。** 地図は画面の上に貼り付いて残り、一覧がその下を流れます (2026-11-19。持ち主の声「Android の Edge で、denpa はスクロールするとアドレスバーが消えるのに、sonae は消えない」)。
  Android のブラウザは窓が巻かれたときだけアドレスバーを隠すので、一覧の箱の中で巻いていたころは隠れませんでした。窓ごと巻くと、アドレスバーが隠れて画面を広く使え、戻ったときに見ていた位置へも帰ります (denpa の一覧の画面と同じ)。
  「一覧」のタブで出し、「地図」のタブで隠します (地図は作り直しません)。選んだもので開いたときは一覧のタブから始まります
  - 一覧のタブの地図の高さは画面の 40% です (`--phone-map-h`)。縦のスマホ (高さ 700px 前後) でも横のスマホ (390px 前後。読む間は dock が引っ込む) でも、地図と、浮いた dock・下のタブを除いて見える一覧が、ほぼ同じ高さになります。sonae は地図が主ですが、一覧のタブは一覧を読む所で、地図だけを大きく見るには地図のタブがあるためです
  - 高さは `vh`・`dvh` で言い当てず、`html` から 100% で受け継いだ外枠の高さから採ります (外枠を大きさの container にして `cqh` で読む。denpa の `app.css` の「画面の高さは、単位ではなく `html` から採る」と同じ考え方)。アドレスバーの出し入れで地図の大きさは変わりません
  - 地図の上で指を動かすと地図が動き、窓は巻きません (MapLibre が地図に `touch-action: none` を付ける)。窓を巻くのは一覧の上です
  - 地図のタブへ移ると一覧は流れの外に出て、窓は巻けなくなります。一覧のタブへ戻ると、巻いていた位置へ帰ります
  - 選び直すと一覧の先頭 (詳しい内容の始まり) へ戻し、戻る・進むでは、その画面で見ていた位置へ帰します (SvelteKit の `snapshot`。行のリンクは `data-sveltekit-reset="false"` で URL だけを替えるので、SvelteKit は窓の位置を戻さない)。広い形の列の箱も同じく戻します
  - 貼り付く日付の見出しは地図のすぐ下に付きます。Tab で移った先は、上の地図と下の dock・下のタブに隠れない所まで巻きます (`scroll-margin`)
  - 窓 (通知・出典と注意) を開いている間は、後ろの一覧は巻けません (`html:has(dialog:modal)`)
- 下のタブのすぐ上に操作の 1 行 (dock) が浮きます。一覧のタブでは種類のチップ (広い形と同じ絞り込み。横に流せる)、地図のタブでは選んでいるもの (地震なら震度と震源、地震でないもの (自動で開いた緊急地震速報など) はその 1 行。押すと一覧のタブの詳しい内容へ移ります) です。何も選んでいないときは、いま出ている命に関わるもの (一覧の先頭にいつも貼るもの) のいちばん上を出し、それも無ければ「一覧から選ぶと、地図とここに出ます」と出します (dock の高さは変えないので、地図の操作の置き場 `--map-bottom` は替わりません)。いま出ている緊急地震速報 (警報) の 1 行は状態の赤で塗ります
  受信に問題があるときだけ、右端に注意の印が出ます (押すと受信の状態)。一覧のタブでは dock が地図に重ならないので、地図の操作は地図の下の端に置きます
- 通知の音か読み上げがオンなのにブラウザが音を止めている間は、画面のいちばん上 (ノッチの下) に広い形と同じ帯が出ます。地図と一覧はその下から始まるので、dock・下のタブ・地図の上の操作を隠しません (一覧のタブでは、帯は一覧と一緒に巻かれて上へ出ていきます)
- 一覧の先頭に地名で絞り込み・住所で探す欄 (広い形と同じ場所の候補。選ぶと地図のタブへ移ります)、いちばん下に注意文と短い出典があります。詳しい内容の上の「地図で見る」で地図のタブへ移ります。地図は選んだときに寄せてあるので、タブを移っても寄せ直しません ([map.md](map.md))
- **下のタブはいつも出します。** 低い画面 (高さ 600px 未満。横向きのスマホ) で一覧を下へ読む間だけ、dock が引っ込みます (denpa と同じ条件。`#lib/retract.ts`。2026-11-19 に持ち主の声「メニューバーが隠れる条件を denpa と同じにしてほしい」で、下のタブも引っ込めていたのをやめた)。
  先頭から 48px までは出し、下へ 4px より多く送ると引っ込め、上へ 4px より多く戻すと出します。見るのは窓の巻いた量で、人が一覧の中を巻いたときだけです。選び直して先頭へ戻したときや、戻る・進むで見ていた位置へ帰したときは出し入れしません。選ぶ・戻るで画面が替わったときと、地図のタブに移ったときは出します。キーボードで dock の中に触っている間は引っ込めません
- 読み上げている間の「読み上げ中断」は、dock のすぐ上の左に浮きます (広い形と同じく、押すか Esc で止まります)
- 下のタブは denpa の 640px 未満と同じ 5 つまで (2026-11-15 に 3 つから増やした。持ち主の声「スマホのときメニューバーの項目もうちょい増やして3つだと少ない」)。「通知」は通知の窓を開き (広い形のヘッダーの「通知」と同じ)、「強震モニタ」は防災科研の公式のページを新しいタブで開きます。どちらもよく使うので外に出し、タブに出したものは「その他」に入れません (denpa の 6 章)。「出典と注意」は地図の隅と一覧の下の出典からいつも開けるので、タブには出しません
- 「その他」には利用者の名前、「出典と注意」(受信の状態もここ)、テーマ、ログアウトがあります。いま出ている緊急地震速報 (取消を除く) の詳しい内容にも「強震モニタを開く」があります (どちらの形も)

## 自動で開く

人が押さなくても、次の 2 つは詳しい内容を自動で開きます (`#lib/auto-open.ts`。2026-11-15。持ち主の声「情報読み上げ中は詳細開いてほしいかも」「緊急地震速報も上に表示するんじゃなくてサイドバーで詳細表示にすればいいと思う」)。

- **読み上げ始めた報。** 「通知」の音と読み上げが「読み上げも」のときだけです (「オフ」「通知音だけ」で、音か OS の通知だけのときは開きません。聞いていないのに画面が替わると、何が起きたか分からないため)。開くのは原稿を読み始めるとき (音の 0.75 秒後) です
- **出た緊急地震速報 (取消を除く。訓練・試験は除く)。** 読み上げがオフでも開きます。前の画面の上の帯はやめ、帯に出していたもの (警報は「強い揺れに警戒」と警報の地域、震源・深さ・M・仮定震源、第何報・発表の時刻・情報源、強震モニタを開く) を詳しい内容の先頭の箱に出します。警報の箱は状態の赤で塗り、`role="alert"` で読み上げソフトにも伝わります。
  続報は同じ箱がその場で替わります。予報から警報に上がったときは、もう一度開きます。予想震度は出しません (design.md の 5 章)

開き方は一覧の行を押したときと同じで、URL の query (`?e=<識別番号>` など) が替わり、地図はいつもの決まりでその報へ寄ります ([map.md](map.md) の「描き方の決まり」)。

| いまのようす                                        | 命に関わるもの (緊急地震速報・大津波警報と津波警報・特別警報) | ほかのもの                                            |
| --------------------------------------------------- | ------------------------------------------------------------- | ----------------------------------------------------- |
| 何も選んでいない                                    | 開く                                                          | 開く                                                  |
| 前に自動で開いたものを見ている (人は動かしていない) | 開く (置き換える)                                             | 開く (置き換える)                                     |
| 人がほかのものを選んで見ている                      | 開く                                                          | 開かない                                              |
| 窓 (通知・出典と注意) を開いている                  | 窓を閉じて開く                                                | 開かない                                              |
| 出ている緊急地震速報を見ている                      | 緊急地震速報だけ開く                                          | 同じ地震の地震情報だけ開く (窓が開いていれば開かない) |

- 命に関わるものは、一覧の先頭にチップにかかわらずいつも貼るものと同じです。人が見ているものより、身を守る動きを先にします
- **緊急地震速報の後に同じ地震の地震情報が来たら、そちらに替えます** (2026-11-17。持ち主の声「読み上げは地震情報読み上げるけど画面が変わらん」)。同じ地震かは地震識別番号で見て、無ければ (P2P だけの震度速報など) 発生時刻か震度速報の対象の時刻が 3 分以内かで見ます (`followsEew`)。緊急地震速報を人が自分で開いていても替えます (戻るで緊急地震速報へ戻れます)
- **読み終えた後も開いたまま**にします (読み終えたところで消えると、見返せない)。続けて別の報を読むときは、その報に置き換えます (声と画面を合わせる)
- **緊急地震速報は、出ている間 (最後の報から 3 分。最終報・取消も同じ) を過ぎたら、自動で開く前にいた所へ戻ります。** ただし人がその間にほかの所へ移ったときと、読み直したとき (自動で開いた控えはメモリだけに持つ) は戻りません。取消のときは、箱が「緊急地震速報は取り消されました」に替わり、3 分たつと戻ります
- **履歴は積み上げません。** 人が見ていた所から開くときは 1 つ積み (戻るで元の所へ)、自動で開いたものを替えるときは置き換えます。続けて幾つ読んでも、戻る 1 回で自動で開く前の所へ戻ります。読み上げと緊急地震速報が同じ報を続けて開こうとしたときも 1 つだけです
- **スマホの形ではタブを替えません。** 一覧のタブなら詳しい内容が出て、地図のタブなら地図がその報へ寄り、dock にその報の 1 行が出ます (いま出ている緊急地震速報 (警報) は状態の赤)。dock を押すと一覧のタブの詳しい内容へ移ります
- 開いた緊急地震速報は、地図にいつも出します (震央の × と警報の地域)

## URL

何を見ているかは URL の query に持ちます (`#lib/view.ts`)。リンクを送れば同じ所が開きます。どの種類を一覧に出すかは端末ごとの絞り込みなので、URL には持ちません。
前の一覧の種類 `k` (`?k=tsunami` など) は読まず、画面の中のリンクを作るときに外します (前のリンクは全部の種類の一覧で開きます)。
前の訓練・試験を出す印 `training=1` も同じく読まずに外します。緊急地震速報の訓練・試験は、サーバーの環境変数 `SONAE_TRAINING=on` のときだけ一覧と地図に出します (既定は出しません。出しても音・読み上げ・通知では知らせません。[design.md の 2.2](design.md#22-正規化したイベントのモデル))。
既定のままでも、訓練・試験の `?e=<識別番号>` のリンクを開けば詳しい内容を出します。そのときは先頭に「訓練」(試験なら「試験」) を大きく出し、「訓練の緊急地震速報です。実際の地震ではありません。」と添えて、本物と取り違えないようにします。

| query     | 意味                                                                                    |
| --------- | --------------------------------------------------------------------------------------- |
| `q`       | 選んだ地震の id                                                                         |
| `t`       | 選んだ津波の id                                                                         |
| `e`       | 選んだ緊急地震速報の地震の識別番号                                                      |
| `v`       | 選んだ火山の報の id                                                                     |
| `w`       | 選んだ気象。府県予報区の警報・注意報は `office-<府県予報区のコード>`、気象の報はその id |
| `i`       | 選んだお知らせの id                                                                     |
| `f`       | 選んだ海外の地震の id                                                                   |
| `about=1` | 「出典と注意」の窓を開く                                                                |

選んだものがいまの一覧 (新しい 100 件など) に無いときは、サーバーが DB から引きます (`+page.server.ts`)。DB にも無ければ「この情報はありません」と出します。
府県予報区の警報・注意報 (`?w=office-<コード>`) は、出ているものが無くなると一覧から外れます。そのリンクを開いたときに、受けた報から全部解除されたと分かれば「<府県予報区>の警報・注意報は解除されました」と、解除した報の時刻を出します (開いている間に解除されたときも同じ)。報を受けていないなど、解除されたと分からないときは「この情報はありません」のままです。

前の画面の URL は、ログインの後に 301 で送ります (`hooks.server.ts`)。

| 前の URL                         | 送り先      |
| -------------------------------- | ----------- |
| `/quakes/<id>`                   | `/?q=<id>`  |
| `/tsunami/<id>`                  | `/?t=<id>`  |
| `/tsunami`                       | `/`         |
| `/eew` (`?training=1` は外す)    | `/`         |
| `/map` (`?quake=<id>` は `q` に) | `/`         |
| `/about`                         | `/?about=1` |
