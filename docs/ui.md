# 画面

sonae の画面は 1 つです (`src/routes/+page.svelte`)。地図が主で、地震・津波・緊急地震速報の一覧、選んだものの詳しい内容、受信の状態、地図の層の切り替えを同じ画面に置きます。
見た目の決まりは [design.md](design.md) の 6 章 (denpa の決まりに従う) です。

## 広い形 (1000px から)

- 上に全幅のヘッダー。左にロゴと名前、真ん中に地名で絞り込む欄 (`/` か Ctrl+K で移る)、右に字だけのナビ (「出典と注意」・「通知」(通知の条件、開いているときの音と読み上げ、Web Push。[push.md](push.md))・利用者の名前のメニュー)。
  利用者のメニューには「強震モニタを開く」(防災科研の公式のページを新しいタブで開く)、テーマ (暗い・明るい・端末に合わせる) とログアウトがあります。受信に問題があるときは、ナビの左に注意の印と一言が出ます。通知の音か読み上げがオンなのにブラウザが音を止めている間は、ナビの左に「音を出す」が出ます (押すと鳴らせるようになる。[design.md の 2.4](design.md#24-web-push))
- その下は 3 列です。左が一覧、真ん中が地図、右がサイドバーです。一覧とサイドバーはそれぞれの中で巻きます
- 一覧は件の面に乗った行が日付の見出しごとに並びます。行は 2 段で、1 段目に時刻とタイトル (震源・区分)、2 段目に控えた字の補足 (M・深さ・警報の地域) です。地震の行の左には震度のラベルが付きます
- 一覧の上には、いま出ている津波の警報・注意報・予報と、1 日以内の噴火速報・いま出ている噴火警報 (居住地域)、この 1 週間の南海トラフ地震の情報・お知らせが通知の形で出ます。押すと「お知らせ」の詳しい内容が開きます
- 長周期地震動階級 1 以上を観測した地震は、行の 2 段目に「長周期地震動階級3」と出ます。地震の詳しい内容には「長周期地震動」の節があります ([design.md の 2.7](design.md#27-長周期地震動と推計震度分布))
- 海外の地震 (USGS など) は一覧の種類「海外」に並びます。地図の初めの範囲は日本のままで、海外の地震を選ぶと地図が引いてその震央へ寄ります
- 行を押すと、一覧の列が詳しい内容に替わり、地図もその地震に寄ります。左上の「一覧」で戻ります
- サイドバーは上から、月のカレンダー (行のある日を押すとその日の見出しへ送る)、状態 (画面への配信と、情報源ごとの受信)、絞り込み (地震・津波・緊急地震速報・火山・海外・お知らせ。件数つき)、表示 (地図の層のオン/オフと、緊急地震速報の訓練・試験)、注意文と出典です

## スマホの形 (1000px 未満)

- ヘッダーとサイドバーは出しません。地図が画面いっぱいに出て、下に下のタブ (地図・一覧・その他) が浮きます
- 一覧は地図の上に重ねる面です。「一覧」のタブで出し、「地図」のタブで隠します (地図は作り直しません)。選んだもので開いたときは一覧のタブから始まります
- 下のタブのすぐ上に操作の 1 行 (dock) が浮きます。一覧のタブでは一覧の種類のチップ (件数つき)、地図のタブでは地図に出している地震です。右端の「⋯」で状態と表示 (層) を開きます。受信に問題があるときは「⋯」が注意の印に替わります。通知の音か読み上げがオンなのにブラウザが音を止めている間は、「⋯」の左に「音を出す」が出ます
- 一覧の先頭に地名で絞り込む欄、いちばん下に注意文と出典があります。詳しい内容の上の「地図で見る」で地図のタブへ移ります。地図のタブに移ったとき、選んだ地震の震央が画面の外なら地図がそこへ寄ります ([map.md](map.md))
- 一覧を下へ読む間は、下のタブと dock が引っ込みます
- 「その他」には利用者の名前、「出典と注意」、「通知」、「強震モニタを開く」、テーマ、ログアウトがあります。緊急地震速報 (取消を除く) の帯にも「強震モニタを開く」があります (どちらの形も)

## URL

何を見ているかは URL の query に持ちます (`#lib/view.ts`)。リンクを送れば同じ所が開きます。

| query        | 意味                                                                                                       |
| ------------ | ---------------------------------------------------------------------------------------------------------- |
| `k`          | 一覧の種類 (`quake` 地震・`tsunami` 津波・`eew` 緊急地震速報・`volcano` 火山・`foreign` 海外の地震・`info` お知らせ)。既定は地震 |
| `q`          | 選んだ地震の id                                                                                            |
| `t`          | 選んだ津波の id                                                                                            |
| `e`          | 選んだ緊急地震速報の地震の識別番号                                                                         |
| `v`          | 選んだ火山の報の id                                                                                        |
| `i`          | 選んだお知らせの id                                                                                        |
| `f`          | 選んだ海外の地震の id                                                                     |
| `training=1` | 緊急地震速報の訓練・試験も出す                                                                             |
| `about=1`    | 「出典と注意」の窓を開く                                                                                   |

選んだものがいまの一覧 (新しい 100 件など) に無いときは、サーバーが DB から引きます (`+page.server.ts`)。DB にも無ければ「この情報はありません」と出します。

前の画面の URL は、ログインの後に 301 で送ります (`hooks.server.ts`)。

| 前の URL                          | 送り先               |
| --------------------------------- | -------------------- |
| `/quakes/<id>`                    | `/?q=<id>`           |
| `/tsunami/<id>`                   | `/?k=tsunami&t=<id>` |
| `/tsunami`                        | `/?k=tsunami`        |
| `/eew` (`?training=1` はそのまま) | `/?k=eew`            |
| `/map` (`?quake=<id>` は `q` に)  | `/`                  |
| `/about`                          | `/?about=1`          |
