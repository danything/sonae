# 地図の層と出典

地図 (1 つの画面の真ん中。スマホの形は「地図」のタブ。[docs/ui.md](ui.md)) は MapLibre GL JS で描く (選んだ理由は docs/design.md の 4 章)。
下地は国土地理院のシームレス空中写真で、その上に付加情報の層を重ね、**層ごとにオン・オフできる**。
オン・オフは端末に覚えさせる (localStorage の `sonae.map.layers`)。

機能は Zero Quake の「付加情報を重ねて切り替えられる」ことだけを参考にした。コードは読んでいない。

## 層と、そのデータの出典・ライセンス

| 層                 | 既定 | データ                                                                                                                | 出典・ライセンス                                                                                                                                                                                                                                                                                                                                    |
| ------------------ | ---- | --------------------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |

細分区域と津波予報区の GeoJSON は `tools/areas/build.sh` で作り、`static/areas/` に置く (mapshaper で簡略化。
細分区域 約 870KB・gzip 約 200KB、津波予報区 約 300KB・gzip 約 80KB)。気象庁の GIS データの更新 (年に 1〜2 回) を
受けたら作り直す。GIS データのページにある「国土地理院長の承認を得て…」の文は、気象庁がそのデータを作るときの承認で、
sonae の画面には気象庁の GIS データの出典を出す。

## 入れなかったもの

| もの                      | 理由                                                                                                                                                                            |
| ------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| プレート境界              | 国土地理院の地理院タイルの一覧にも、気象庁の GIS データにも無い。ほかの機関のデータ (研究用の境界の線) は利用条件をそれぞれ確かめる必要があり、公式のデータに絞る方針から外した |
| 観測点ごとの震度の点      | 震度観測点の緯度・経度を、気象庁が機械で読める形で出していない。地域 (細分区域) ごとの震度で塗る                                                                                |
| 地図の字 (ベクトルの注記) | 地理院のベクトルタイルは提供の形が変わりうる。字を描く字体 (glyphs) を外から読むのも避けたいので、地名は淡色地図のラスターで重ね、震度の札は DOM の印で置く                     |
| PMTiles                   | いまの区域の GeoJSON は小さく、そのまま読める。区域を細かくする (市町村など) ときに考える                                                                                       |

## 描き方の決まり (docs/design.md の 6 章)

- カメラは飛ばさない (`jumpTo`)。寄せるのは、選んだ地震か、出ている緊急地震速報が替わったときだけ (続報で勝手に動かない)。
- 地図を回さない (北が上)。
- 動くのは緊急地震速報の震央の × が出たときの 3 回の脈打ちだけ (`transform: scale`)。動きを減らす設定では止まる。
- WebGL が使えない端末では地図を出さず、一覧で見てもらう。
- MapLibre (約 1.1MB) は画面を描いた後に動的 import で読む (最初の表示と一覧は待たせない)。
